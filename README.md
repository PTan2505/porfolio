# Portfolio — Nguyễn Phúc Tần

Personal portfolio of a frontend developer based in Ho Chi Minh City. Monochrome, motion-heavy, multi-page.

- **Stack:** Vite + React 19, Tailwind CSS v4, React Router, Motion, GSAP, [React Bits](https://reactbits.dev) components (Tech Text, Grid Scan, Split Text, Logo Loop, Magnet, Click Spark, Scroll Velocity).
- **Pages:** Home, `/work`, `/work/:slug`, `/about`.
- **Content:** `src/data/site.js` and `src/data/projects.js`.

```bash
npm install
npm run dev
```
